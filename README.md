# Sahil Potale — Portfolio

React + Vite portfolio.

    npm install
    npm run dev      # local preview
    npm run build    # production build in dist/

Deploy on Vercel: import this repo, framework preset "Vite" (auto-detected), then Deploy.
Edit your content in `src/App.jsx` (PROJECTS, SKILLS, FIELDS). Replace `public/me.jpg` to change the photo.
